# قائمة مراجعة جودة UI

## Layout
- [ ] لا يوجد Overflow.
- [ ] SafeArea صحيحة.
- [ ] المسافات متناسقة.
- [ ] تعمل على شاشة صغيرة.
- [ ] تعمل على شاشة كبيرة.
- [ ] Bottom CTA لا تختفي.

## RTL
- [ ] اتجاه النص صحيح.
- [ ] Icons صحيحة.
- [ ] Back arrow صحيح.
- [ ] الأرقام والأسعار مقروءة.
- [ ] Map overlays مناسبة للعربي.

## Typography
- [ ] الأحجام من Tokens.
- [ ] لا يوجد Font عشوائي.
- [ ] Line height مناسب.
- [ ] العناوين واضحة.

## Colors
- [ ] Primary ثابت.
- [ ] Status colors صحيحة.
- [ ] Contrast جيد.
- [ ] Disabled واضح.
- [ ] Error لا يعتمد على اللون فقط.

## Components
- [ ] استخدام Shared Components.
- [ ] لا يوجد Button مختلف بلا سبب.
- [ ] لا يوجد Card مكرر.
- [ ] Radius من Tokens.
- [ ] Spacing من Tokens.

## Interaction
- [ ] CTA الأساسي واضح.
- [ ] Tap target >= 44px.
- [ ] Loading state.
- [ ] Disabled state.
- [ ] Duplicate taps ممنوعة.
- [ ] Keyboard لا يغطي CTA.

## States
- [ ] Loading.
- [ ] Empty.
- [ ] Error.
- [ ] No Internet.
- [ ] Retry.
- [ ] Reconnect.
- [ ] Success.

## Forms
- [ ] Validation واضحة.
- [ ] Error message مفهومة.
- [ ] Keyboard type مناسب.
- [ ] Submit disabled أثناء الإرسال.

## Maps
- [ ] Location permissions handled.
- [ ] GPS disabled handled.
- [ ] Map loading handled.
- [ ] Route loading handled.
- [ ] Markers واضحة.

## Bidding
- [ ] Customer Price واضح.
- [ ] Driver Offer واضح.
- [ ] Selected Offer واضح.
- [ ] Expired Offer غير قابلة للاختيار.
- [ ] Realtime لا يسبب Jump مزعج.

## Driver Safety
- [ ] الأزرار كبيرة.
- [ ] لا يوجد نص طويل أثناء الحركة.
- [ ] Status الحالي ظاهر.
- [ ] CTA التالي واضح.

## Final Visual Review
- [ ] تبدو الشاشة جزءًا من نفس التطبيق.
- [ ] المستخدم يفهم هدفها خلال ثانيتين.
- [ ] CTA الرئيسي واضح فورًا.
- [ ] لا يوجد عنصر زائد يمكن حذفه.
- [ ] Screenshot الشاشة يبدو نظيفًا.
